# Сайт-портфолио художницы

Простой сайт с четырьмя разделами (Главная, Галерея, Награды, Выставки) и
админкой для их редактирования. Все тексты и фотографии хранятся в этом же
GitHub-репозитории — отдельная база данных не нужна, ничего не потеряется
при перезапуске сайта.

## Как всё устроено (коротко)

- **GitHub** — здесь лежит код сайта и все данные (`data/content.json`) и
  фотографии (`data/images/`).
- **Render** — здесь сайт "живёт" в интернете. Render автоматически берёт код
  из GitHub и запускает его.
- **Админка** (`/admin`) — защищённая паролем страница, на которой можно
  добавлять, менять и удалять картины, награды, выставки и текст на главной.
  Каждое сохранение в админке сразу отправляется в GitHub и мгновенно видно
  на сайте.

## Установка (делается один раз)

### Шаг 1. Создать репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и создайте аккаунт, если его нет.
2. Создайте новый **приватный** репозиторий, например `artist-portfolio`.
3. Загрузите в него все файлы этого проекта (через "Add file → Upload files"
   на сайте GitHub, либо через git, если вы им пользуетесь).

### Шаг 2. Создать токен доступа GitHub

Токен — это "ключ", который позволяет сайту сохранять данные в репозиторий.

1. Откройте [github.com/settings/tokens](https://github.com/settings/tokens)
   → **Generate new token** → **Fine-grained token**.
2. Дайте токену имя, например `artist-portfolio`.
3. В разделе **Repository access** выберите **Only select repositories** и
   укажите ваш репозиторий `artist-portfolio`.
4. В разделе **Permissions → Repository permissions** найдите **Contents** и
   поставьте **Read and write**.
5. Нажмите **Generate token** и скопируйте его — он показывается только один
   раз, сохраните в надёжном месте.

### Шаг 3. Разместить сайт на Render

1. Зайдите на [render.com](https://render.com) и войдите через свой аккаунт
   GitHub.
2. Нажмите **New → Web Service** и выберите репозиторий `artist-portfolio`.
3. Render сам предложит настройки из файла `render.yaml` — можно оставить
   их как есть (тариф **Free**).
4. В разделе **Environment** заполните переменные:
   - `ADMIN_PASSWORD` — пароль, который вы сами придумаете для входа в админку.
   - `SESSION_SECRET` — любой длинный набор случайных букв и цифр (например,
     `a8f92dksldk29fjaLKDs82`).
   - `GITHUB_OWNER` — ваше имя пользователя на GitHub.
   - `GITHUB_REPO` — название репозитория, например `artist-portfolio`.
   - `GITHUB_BRANCH` — оставьте `main`.
   - `GITHUB_TOKEN` — токен, скопированный в Шаге 2.
5. Нажмите **Deploy**. Через пару минут появится ссылка на сайт вида
   `https://artist-portfolio.onrender.com` — это и есть готовый сайт.

Готово. Теперь можно зайти на `<адрес сайта>/admin`, ввести пароль из
`ADMIN_PASSWORD` и начать заполнять сайт.

## Как пользоваться админкой

- Откройте `<адрес сайта>/admin`, введите пароль.
- Вверху — четыре вкладки: **Главная**, **Галерея**, **Награды**, **Выставки**.
- Чтобы добавить картину, награду или выставку — заполните форму вверху
  вкладки и нажмите кнопку.
- Чтобы изменить уже добавленное — нажмите **«Изменить»** под нужной записью,
  откроется форма с текущими данными.
- Чтобы удалить — нажмите **«Удалить»** и подтвердите (это нельзя отменить).
- После каждого сохранения наверху появляется зелёная надпись «Сохранено ✓»,
  и изменения сразу видны на сайте.

## Важно знать

- Бесплатный тариф Render «засыпает» после 15 минут без посетителей — первый
  заход после паузы может занять около минуты, дальше всё работает быстро.
- Раз в месяц у Render обнуляется лимит бесплатных часов — для одного
  небольшого сайта его более чем достаточно.
- Все фотографии и тексты хранятся в GitHub-репозитории, поэтому у вас всегда
  есть их резервная копия — ничего не пропадёт, даже если Render когда-нибудь
  перезапустит сайт.

## Локальный запуск (для разработчика)

```bash
npm install
cp .env.example .env   # и заполнить значения
npm start
```

Сайт будет доступен на `http://localhost:3000`.
